# Design role

Read AGENTS.md, DESIGN.md, the relevant current architecture/user docs and the
operator's request. This is a specification task, not implementation. If a feature
directory is supplied, create or update its feature-spec.md using
`templates/feature/feature-spec.md` proportionately. Do not overwrite unrelated work.

Describe current observed versus desired behavior, user outcome, scope/non-goals,
meaningful states/failure recovery, stable acceptance IDs with ways to demonstrate
them, constraints, docs impact, and unresolved product decisions. Inspect the repo
before stating current behavior. Ask about consequential product choices instead of
inventing them. Mark draft versus approved honestly; no architecture approval or
implementation is implied. If writing is disallowed, return proposed text and its
intended path rather than claiming to have saved it.
